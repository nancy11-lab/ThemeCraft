# ThemeCraft
A customizable landing page built with **HTML, CSS, and JavaScript**.

## Features
- Toggle **dark/light mode**  
- Choose whether the **header is fixed** or not  
- Show or hide **navigation bullets** that link to page sections  
- Enable or disable **random background images** that change every few seconds  
- Pick a **theme color** from a preset color palette applied throughout the project  

## Data Persistence
All user preferences are saved in **localStorage**, so they remain after page reloads.

## Reset Option
A **Reset** button restores all settings to their default values.
